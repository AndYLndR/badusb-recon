# Security Policy

## Sobre este repositorio

Este repositorio se publica con fines **exclusivamente educativos y de investigación**
en seguridad ofensiva y defensiva. Forma parte de un laboratorio personal de BadUSB
con Flipper Zero.

## Reportar problemas de seguridad

Si detectas:

- Un uso indebido de este contenido por parte de terceros.
- Un problema en el código que pueda provocar daños no intencionados.
- Cualquier preocupación ética o legal sobre el proyecto.

Por favor, contacta **antes** de escalar a GitHub:

- 📧 Email: **14nd3r@proton.me**
- 🐛 Issues: abre un issue en este repositorio (para temas no sensibles)

## Compromiso

- Todo el contenido aquí es para entornos propios y autorizados.
- No se acepta contribución alguna que tenga como objetivo atacar sistemas ajenos.
- Se retirará cualquier contenido que se demuestre malintencionado.

## Divulgación responsable

Si encuentras una vulnerabilidad relacionada con este proyecto, te pedimos
que nos des un margen razonable antes de hacerla pública.
